# Finny

Finny — мобильное обучающее приложение для детей на **Expo / React Native / TypeScript**. Ребёнок ухаживает за питомцем и на игровых монетах учится планировать расходы, копить на цели и проверять оплату. Основные платформы — Android и iOS. Веб-режим служит для разработки.

> описание продукта, маршрут приёмки и состав передачи находятся в первых и последних разделах. Команды разработчика собраны отдельно.

## Возможности

| Раздел | Возможности |
| --- | --- |
| Знакомство | Игровое имя, выбор цвета, вылупление питомца, имя питомца. |
| Дом | Питомец, баланс, уровень, серия входов, подсказки и ежедневная награда. |
| Еда | Кормление и покупка еды за игровые монеты. |
| Гардероб | Просмотр, покупка и надевание головных уборов. Уже купленная вещь повторно не оплачивается. |
| Копилка | Переводы со счёта и обратно, цели, накопление и покупка достигнутой цели. |
| Учёба | Три главы, интерактивные задания, награды за уроки и главы. |
| Прогресс и история | XP, уровень, завершённые уроки и операции с монетами. |
| Взрослый раздел | Локальный четырёхзначный PIN, просмотр целей и учебного прогресса ребёнка. |

Программа содержит **11 уроков**:

| Глава | Уроков | Темы |
| --- | ---: | --- |
| Бюджет | 4 | Необходимое и желания; «Сейчас / Позже»; поход с резервом 30 монет; карточки «верно / неверно». |
| Сбережения | 4 | Мечта и цель; недельный взнос; сортировка монет 1/3/5; повторение. |
| Платежи и покупки | 3 | Проверка баланса; оплата роликов за 75 монет и сдача; повторение. |

После прохождения главы «Бюджет» питомец взрослеет. На экране завершения главы пользователь распределяет бюджет между категориями
## Первый запуск и игровые правила

**Стартовый сценарий на чистом сохранении:** `0 монет → ежедневная награда +10 → яблоко −5 → остаток 5 → колпак стоит 16 → не хватает 11 → первая цель «Колпак в точечку» на 15 → первый урок`. Цена колпака в гардеробе и сумма учебной цели различаются намеренно. Меняя цены, награды или подсказки, проверяйте всю цепочку. Она также зафиксирована в [AGENTS.md](AGENTS.md).

- **Счёт и копилка** — разные балансы. Перевод меняет оба; покупка цели списывает полную стоимость из общей копилки. Монеты не закреплены за конкретной целью.
- **Цели** не предлагаются, если соответствующий предмет уже куплен или цель уже существует. Купленный в гардеробе колпак не предлагается как цель. Повторная покупка цели не списывает монеты.
- **Ежедневная награда** — 10 монет раз в календарный день; последовательные входы увеличивают серию.
- **Награда за урок** — 30 монет и 25 XP один раз для каждого завершённого урока. Точность сохраняется.
- **Награда за главу** — ещё 30 монет и 25 XP один раз. Уровень повышается после каждых 100 XP.
- Урок можно пройти повторно, но его награда повторно не выдаётся. В истории хранятся последние 100 операций с монетами.

Монеты и покупки **игровые**. Подключения к банковским счетам и реальных платежей нет.


## Установка и запуск

**Требования:** Node.js, npm, Git и доступ к репозиторию. Проверенная комбинация — **Node.js 24.12.0 / npm 11.19.0**; другие версии проверяйте отдельно, особенно для тестов, импортирующих TypeScript напрямую через Node. Для Android нужен телефон или эмулятор; iOS Simulator работает на macOS. Для облачной сборки нужен доступ к Expo-проекту.

В корне репозитория:

```bash
npm ci
npm start
```

`npm ci` использует `package-lock.json`. Metro покажет QR-код. Компьютер и телефон обычно должны быть в одной сети. В Expo CLI клавиша `a` открывает Android Emulator, `i` — iOS Simulator на macOS. При проблемах с локальной сетью попробуйте `npx expo start --tunnel`. [Руководство Expo](https://docs.expo.dev/get-started/start-developing/).

```bash
npm run android   # Expo CLI и Android-эмулятор
npm run ios       # Expo CLI и iOS Simulator на macOS
npm run web       # веб-режим разработки
```

Это команды разработки, **не создание APK/AAB/IPA**. Если Expo Go сообщает об отсутствующем нативном модуле, используйте собственную сборку. Для development build пакет `expo-dev-client` придётся установить: сейчас его нет в `package.json`. После добавления нативной зависимости приложение нужно пересобрать. [О development build](https://docs.expo.dev/develop/development-builds/introduction/).

### Демонстрационные данные для QA

`EXPO_PUBLIC_FINNY_TEST_DATA=1` включает отдельные случайные демонстрационные данные и отдельные ключи локального хранилища. Пример для PowerShell:

```powershell
$env:EXPO_PUBLIC_FINNY_TEST_DATA = '1'
$env:EXPO_PUBLIC_FINNY_TEST_SEED = 'review-1'
$env:EXPO_PUBLIC_FINNY_TEST_SESSION = 'qa-1'
npm start
```

Для проверки реального первого запуска выключите режим, перезапустите Metro и очистите данные обычной тестовой установки:

```powershell
Remove-Item Env:EXPO_PUBLIC_FINNY_TEST_DATA -ErrorAction SilentlyContinue
Remove-Item Env:EXPO_PUBLIC_FINNY_TEST_SEED -ErrorAction SilentlyContinue
Remove-Item Env:EXPO_PUBLIC_FINNY_TEST_SESSION -ErrorAction SilentlyContinue
npm start
```

Переменные `EXPO_PUBLIC_*` попадают в клиентский bundle: **не помещайте туда секреты**. [Документация Expo](https://docs.expo.dev/eas/environment-variables/usage/).

## Проверки качества

```bash
npm run typecheck
npm test
npx expo export --platform android --output-dir dist/check-android
```

`typecheck` проверяет TypeScript. `test` запускает **6 модульных тестов** правил целей, покупок и наград; они не заменяют тесты экранов и локального хранилища на устройстве. `expo export` проверяет сборку Android JavaScript bundle через Metro, **не создаёт APK**. Каталог `dist/` исключён из Git. Перед выпуском выполните проверки и маршрут приёмки в устанавливаемой сборке на обеих платформах.


## Данные, безопасность и ограничения

- Профиль и игра сохраняются **локально** через AsyncStorage (`finny-profile` и `finny-game`). Учётных записей игрока, синхронизации устройств и серверной резервной копии в коде нет.
- Взрослый PIN хранится локально под ключом `finny-parent-pin`. Это защита от случайного входа ребёнка, **не криптографическая защита данных**. Восстановления PIN без потери данных в приложении нет.
- Очистка данных или удаление приложения может привести к потере прогресса. Проверяйте сброс только на тестовом устройстве.
- В проекте нет собственной серверной части или реальных платежей. Expo/EAS используются при разработке и сборке.
- Флаги звука и уведомлений присутствуют в профиле, но их наличие само по себе не означает готовую систему звука или push-уведомлений.
- Веб-режим не заменяет приёмку мобильных жестов, safe area и клавиатуры на Android/iOS.
