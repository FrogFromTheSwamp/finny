# Asset map

- `rooms/home-room.png` — комната главного экрана из экспортов «окружение».
- `rooms/kitchen.png` — кухня для кормления.
- `characters/*` — обычные и открывающие рот состояния питомца.
- `food/fruits`, `vegetables`, `ready`, `sweets`, `vitamins`, `drinks` — разрезанные на отдельные файлы продуктовые спрайты из SVG-экспортов.
- `ui/streak-fire.png`, `tap-hand.png`, `category-basket.png` — отдельные UI-ассеты, извлечённые из SVG.
- `reference/*` — контрольные экспорты исходных экранов, по которым сверялась компоновка.
