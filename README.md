# Finny

Мобильное обучающее приложение на Expo / React Native. В проекте реализованы онбординг питомца, дом, кормление, магазин еды, 3 учебные главы (12 интерактивных уроков), награды, цели накоплений, пополнение и снятие, покупки целей, история операций и план расходов 50/30/20 с настраиваемыми долями.

## Запуск

```bash
npm install
npm start
```

Для проверки типов:

```bash
npm run typecheck
```

Состояние игры и профиль сохраняются локально через AsyncStorage.
