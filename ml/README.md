# ML-часть Finny

- `finny_sim/` — генератор синтетических данных: виртуальные дети учатся (41 задание из `content/lessons.json`)
  и распоряжаются монетами по правилам `content/economy.json`. Чистый Python, внешних библиотек не нужно.
- `notebooks/` — Jupyter-ноутбуки с анализом данных и моделями (BKT, сравнение моделей, калибровка экономики).
- `tests/` — тесты генератора.
- `data/` — сгенерированные данные (в git не попадают, всегда можно пересоздать тем же seed).

## Окружение (один раз)
VS Code: Ctrl+Shift+P → **Python: Create Environment** → **Venv** → Python 3.13 →
отметить `ml/requirements.txt` → OK. Появится папка `.venv` в корне проекта.

## Сгенерировать данные
VS Code: панель **Run and Debug** (Ctrl+Shift+D) → в списке вверху выбрать
**«Генератор синтетических данных»** → ▶.
Или в терминале VS Code: `cd ml` и `python -m finny_sim --children 300 --weeks 8 --seed 42`.

Результат — CSV-файлы в `ml/data/sim_v3/` (описание таблиц — в начале `finny_sim/simulate.py`).

В каталоге v2 номер попытки начинается с 1 для каждой пары «сессия — задание». В `events.csv` поле `prior_sessions` показывает число предыдущих сессий ребёнка с этим заданием. Версии учебного каталога и экономики записываются в `meta.json`. Ноутбук 01 сохраняет исторический обзор набора sim_v1.

## Сравнение моделей знаний

Из корня проекта при активной `.venv` выполните `python ml/compare_models.py`. При необходимости зависимости устанавливаются командой `python -m pip install -r ml/requirements.txt`. Вход — `ml/data/sim_v3`, выход — `ml/results/knowledge_models_v1.json`. Файл содержит параметры BKT и PFA для каждого навыка, доли верных ответов по навыкам, состав отложенной выборки, контрольную сумму исходного журнала и метрики.

В VS Code откройте `ml/notebooks/03_knowledge_tracing.ipynb`: сохранены таблица AUC/RMSE, график ошибок по навыкам, интервалы для разности RMSE и ограничения эксперимента. Ноутбук читает результат из JSON; для переобучения запустите скрипт.
