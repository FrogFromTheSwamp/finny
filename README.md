# Finny

Мобильное обучающее приложение на Expo / React Native. В актуальной версии собраны онбординг питомца, игровой дом, кормление, магазин еды, гардероб, копилка и цели, три учебные главы (11 интерактивных уроков), ежедневные и учебные награды, история операций, план расходов и защищённый PIN-кодом взрослый раздел.

## Ключевой стартовый сценарий

На чистом сохранении баланс равен **0 монет**. Первый пользовательский путь построен как единая цепочка:

`0 → ежедневный вход +10 → яблоко −5 → остаётся 5 → просьба о колпаке → колпак стоит 16 → не хватает 11 → первая цель «Колпак в точечку» на 15 → первый урок`.

Рука-подсказка ведёт пользователя по обязательным действиям. После полного прохождения первой главы `budget` экран завершения главы выдаёт финальную награду, предлагает распределить бюджет и показывает взросление Финни. После этого взрослый образ выбранного цвета сохраняется во всём приложении.

## Учебные главы

- **Бюджет** — 4 урока, включая распределение покупок «Сейчас / Позже» и поход с обязательным резервом 30 монет на обратную дорогу.
- **Сбережения** — 4 урока, включая создание цели, расчёт еженедельного накопления и сортировку монет 1/3/5 в соответствующие копилки.
- **Платежи и покупки** — 3 урока, включая покупку из баланса, оплату роликов за 75 монет и расчёт сдачи.

## Ассеты

Нормализованные компоненты из `Components.zip` находятся в `src/assets/library`. Структура и правила именования описаны в `src/assets/README.md`, исходное → новое имя — в `ASSET_MANIFEST.md`.

В runtime не дублируются тяжёлые SVG/PDF-версии тех же компонентов: используется подготовленный набор PNG плюс несколько действительно нужных SVG-иконок. Референсные экраны для QA сохранены отдельно в `design_reference/` и не участвуют в интерфейсе.

## Запуск

```bash
npm install
npm start
```

Проверка типов:

```bash
npm run typecheck
```

Состояние игры и профиль сохраняются локально через AsyncStorage. Для проверки первого сценария используйте чистое хранилище или действие сброса данных приложения.

## QA и передача второму ИИ

- `REWORK_NOTES.md` — что именно переработано;
- `FINAL_QA_REPORT.md` — выполненные статические проверки и обязательный ручной прогон;
- `AI_AUDIT_PROMPT.md` — готовый промпт для второго ИИ, которому разрешены только проверка и маленькие безопасные исправления;
- `ASSET_MANIFEST.md` — полная карта переименования компонентов из `Components.zip`.
